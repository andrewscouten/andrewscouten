### 🔁 inTRuder — Genomics · Tandem Repeats (2026)

Finds novel tandem repeat loci and motifs that reference-based catalogs miss, by scanning the insertions long-read structural variant callers (Sniffles2) already produce instead of assembling whole genomes. Includes a web interface for exploring every candidate locus, with an LLM assistant that answers questions by querying the same tables.
